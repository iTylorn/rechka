# Обезличивание текстов и протоколов — 2.0.0-beta.2

Вход: UTF-8 TXT/Markdown, включая расшифровки очереди и готовые протоколы.
Qwen3-8B/14B работает через OpenVINO на Intel GPU. Сетевых запросов при обработке
нет; установка отсутствующей модели выполняется отдельно через менеджер моделей.
Исходные файлы и аудио сохраняются.

## Один файл или пачка

1. Нажмите **«Обезличить тексты…»**. Результаты завершённой очереди образуют пачку.
   **«Добавить TXT / MD…»** добавляет несколько файлов, **«Убрать файл»** убирает
   выбранный файл только из списка. Верхний список переключает просмотр файлов,
   сохраняя общий словарь. Изменение состава пачки сбрасывает словарь и проверку.
2. Выберите Qwen и нажмите **«Найти сведения»**. Правила дополняют модель при поиске
   имён, компаний, контактов, реквизитов, дат, сумм, проектов и технических сведений.
   Принимаются только значения, встречающиеся в тексте. Название исходной записи,
   указанное внутри расшифровки, тоже предлагается для замены.
3. Проверьте галочки и нейтральные метки `[Участник 1]`, `[Организация 1]` и т. п.
   Одинаковое значение получает общую метку в пачке. Варианты одного имени можно
   связать кнопкой **«Связать выделенные строки»**, ошибочную связь — разъединить.
4. **«Вхождения…»** показывает файл и контекст каждого упоминания. Можно назначить
   разные метки людям с одинаковым именем или разрешить оставить конкретное
   вхождение. Снятая галочка основной таблицы разрешает все вхождения значения,
   кроме индивидуальных решений, уже заданных в окне вхождений. Число индивидуальных
   решений доступно в подсказке колонки «Вхождений».
5. Добавьте пропуски вручную. Выделите узнаваемое описание в исходном просмотре и
   нажмите **«Скрыть выделенный фрагмент»**, если его нужно скрыть целиком. Проверяйте
   падежи, сокращения и ошибки распознавания: автоматически найденные варианты
   являются предложениями, а не полным морфологическим разбором.
6. **«Применить и проверить повторно»** выполняет утверждённые замены программно
   и ищет остаточные сведения. Новые находки требуют просмотра и ещё одного прохода.
   Замена слова «Заказчик» не должна скрывать оставшееся рядом имя «Валентин».
   Разрешённые исключения исключаются из поиска только в утверждённом объёме.
7. Прочитайте результат каждого файла и исключения, отметьте подтверждение просмотра.
   Сохраните копии. Для одного файла предлагается новое нейтральное имя; для пачки
   выберите папку. Выходы называются `Документ_1_обезличено.txt` / `.md`, при совпадении
   добавляется номер. Оригиналы и существующие результаты не перезаписываются.

Правки таблицы, вхождений или модели требуют повторной проверки. Если исходник
изменён сторонней программой, откройте пачку заново. Ошибка модели, неполный ответ
и отмена блокируют сохранение. При ошибке записи пачка может содержать часть уже
сохранённых проверенных файлов; программа сообщит об этом.

## Перед составлением протокола

В настройках включите **«Обезличивать перед составлением протокола»** либо
соответствующую галочку в окне ИИ. По умолчанию она выключена.

Порядок одинаков для ручного и автоматического запуска:

1. Проверьте исходные тексты в открывшемся окне: поиск, замены, повторная проверка,
   подтверждение просмотра и продолжения.
2. Обезличенные копии сохранятся рядом с выбранной исходной расшифровкой под
   нейтральными именами. В генерацию передаётся только проверенный текст, без словаря
   соответствий. При ошибке сохранения обработка останавливается.
3. Черновик протокола остаётся в памяти. В новом окне выполните поиск и повторную
   проверку, согласуйте находки и подтвердите просмотр. Утверждённые нейтральные
   метки не предлагаются как реальные секреты.
4. Выберите новое имя протокола в выбранном ранее формате: TXT, Markdown или HTML.
   HTML создаётся заново с экранированным текстом.

Отмена останавливает продолжение. Непроверенный черновик не записывается на диск.
Изменение исходного файла до экспорта требует повторить проверку. Для отдельной
обработки готового протокола используйте TXT/MD; HTML на вход не поддерживается.

## Хранение и ограничения

Словарь и решения по вхождениям находятся в памяти окна и не записываются в настройки,
журналы или выходные документы. После закрытия словарь нужно составить заново.
Это не защищённое хранилище и не режим удаления оригиналов: аудио, обычная расшифровка
и её существующие журналы остаются локально. Временный файл при публикации содержит
уже проверенный текст.

Замены сохраняют порядок реплик, таймкоды, SPEAKER-метки и текстовую разметку.
Нейросеть не переписывает расшифровку. Полнота автоматического поиска не гарантируется:
косвенные признаки и уникальные сочетания параметров требуют просмотра человеком.
Повторный проход той же модели тоже может пропустить сведения. Word, Excel, PDF
и изменение голоса в этот выпуск не входят.
