# Whisper GUI с диаризацией и локальной LLM

Приложение распознаёт аудио и видео, разделяет речь по спикерам и локально обрабатывает
готовую расшифровку с помощью OpenVINO-модели Qwen3. Все нейросетевые модели запускаются
на Intel GPU.

## Версия 2.0 beta

Распакуйте весь архив `WhisperGUI-2.0.0-beta.1-win64.zip` и запустите `WhisperGUI.exe`.
При отсутствии модели программа предложит скачать Whisper INT8 и установит её
по умолчанию в `%LOCALAPPDATA%\WhisperGUI-Beta\models`. Загрузка возобновляется после
обрыва. Для протоколов и резюме модель Qwen устанавливается отдельно кнопкой
«Модели и обновления...» в окне обработки текста. Компактная модель WeSpeaker уже
включена в архив. Python и FFmpeg пользователю устанавливать не требуется.

Кнопка «Модели и обновления...» проверяет версии Whisper INT8 и FP16, WeSpeaker,
Qwen3-8B и Qwen3-14B. Выберите модели и запустите установку; перед переключением
программа проверит файлы и их совместимость с GPU. Для возврата к прежней модели
есть кнопка «Откатить версию». Настройки беты находятся в
`%APPDATA%\WhisperGUI-Beta`; при первом запуске копируются параметры стабильной
версии, а новые модели хранятся отдельно. Подробности — в `docs/MODELS.md`
исходного комплекта.

Необходимо передавать весь архив: EXE использует библиотеки из папки `_internal`.
Распознавание, диаризация и Qwen работают на совместимом Intel GPU.
Файл `build/WhisperGUI/WhisperGUI.exe`, если он остался после ручной сборки,
является промежуточным артефактом PyInstaller и не запускается отдельно.
Рабочий EXE находится только в `dist/WhisperGUI/` рядом с `_internal`.

## Запуск из исходников

1. Установить Python 3.10 и зависимости:

   `python -m pip install -r requirements.txt`

2. Запустить `start_whisper_gpu.bat`.

Используемые по умолчанию модели находятся уровнем выше папки программы:

- `turbo-gpu/whisper-large-v3-turbo-int8-ov` — распознавание;
- `diarization/wespeaker_fixed.xml` — голоса спикеров;
- `llm-models/Qwen3-8B-int4-ov` — протоколы и резюме.
- `llm-models/Qwen3-14B-int4-ov` — более точный режим протоколов.

## Обработка текста

Кнопка «Обработать текст ИИ» открывает библиотеку промптов. Встроены протокол встречи,
краткое резюме, поручения и анализ разговора с клиентом. Пользовательские промпты
сохраняются в `%APPDATA%\WhisperGUI-Beta\prompts.json`.

Протокол и список поручений проходят дополнительный фактологический проход. Реплики
получают внутренние идентификаторы, после чего приложение программно подставляет точные
таймкоды и отклоняет несуществующие метки. Результат можно сохранить как Markdown, TXT
или HTML рядом с исходной расшифровкой.

## Имена спикеров

После диаризации программа может открыть окно идентификации спикеров. Для каждого
`SPEAKER_*` показывается характерный фрагмент текста. Если найден непрерывный участок речи
длительностью не менее пяти секунд, его можно прослушать непосредственно из исходного
аудио- или видеофайла. Для коротких реплик также доступно воспроизведение самого длинного
фрагмента данного технического спикера. После сохранения строки получают вид
`Андрей (SPEAKER_01): текст реплики`, а исходный TXT перезаписывается атомарно.

Список реальных участников можно заранее сохранить в настройках диаризации или ввести
непосредственно в окне идентификации. Затем для каждой технической метки выбирается имя из
выпадающего списка. Одно имя разрешено назначать любому количеству меток: например,
`SPEAKER_01`, `SPEAKER_07` и `SPEAKER_19` могут быть одним Андреем.

Перед воспроизведением выбранный участок автоматически преобразуется во временный PCM WAV
48 кГц / 16 бит / stereo и проигрывается системным Windows-аудиовыводом. Это обеспечивает
совместимость с исходниками нестандартной частоты, включая 8 и 16 кГц. Цвета текстовых
фрагментов берутся из системной палитры и поддерживают светлую и тёмную темы.

Функцию можно отключить в настройках диаризации. Для повторного редактирования последнего
результата служит кнопка «Имена спикеров». В общем `_multi`-файле из нескольких записей
автоматическое переименование не выполняется, поскольку одинаковые номера спикеров могут
принадлежать разным людям.

Если реальное количество участников известно, его следует указать в поле «Точное
количество спикеров». Авторежим дополнительно ограничивается полем «Максимум в
авторежиме», поэтому случайные акустические вариации не создадут десятки голосов. Порог
объединения работает по правилу: выше значение — меньше отдельных спикеров.

Qwen3-8B INT4 помещается в компьютер с 32 ГБ RAM. Локальная 8B-модель заметно повышает
удобство работы, но итоговый документ всё равно следует просматривать перед официальным
использованием: смысловые неоднозначности исходной речи полностью исключить нельзя.

В окне обработки можно переключаться между режимами «Быстрая — Qwen3-8B» и
«Качественная — Qwen3-14B». На контрольной записи двухпроходная обработка заняла примерно
138 и 207 секунд соответственно. 14B лучше определила исполнителей и открытые вопросы,
но итоговый документ также требует просмотра человеком.
