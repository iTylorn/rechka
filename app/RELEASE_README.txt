WhisperGUI 2.0.0-beta.4 — бета для Windows x64
=============================================

1. Распакуйте весь архив WhisperGUI-2.0.0-beta.4-win64.zip в отдельную папку.
2. Запустите WhisperGUI.exe. Python, OpenVINO и FFmpeg отдельно устанавливать
   не требуется.
   M4A (AAC и ALAC) добавляется как обычный аудиофайл. Системные кодеки не нужны.
3. Если модели Whisper ещё нет, программа предложит скачать и установить
   Whisper large-v3-turbo INT8 (около 0,9 ГБ). Нужен интернет только на время
   скачивания. Прерванную загрузку можно продолжить в этом же окне.
4. Для создания протоколов и резюме нажмите «Обработать текст ИИ». В этом окне
   можно установить Qwen3-8B INT4 (около 4,9 ГБ) или Qwen3-14B INT4
   (около 9,8 ГБ). Эти модели необязательны для распознавания речи.
5. Для обезличивания готовых TXT/Markdown нажмите «Обезличить тексты…».
   Найдите сведения, проверьте галочки и единые замены, затем нажмите
   «Применить и проверить повторно». После подтверждения просмотра сохраните копии.
   Новые находки повторного прохода добавляются в таблицу для проверки.
   Словарь замен не сохраняется; исходный TXT и аудио не изменяются.
   Подробности и ограничения описаны в разделе обезличивания файла README.md.
6. «Вхождения…» позволяет различать людей с одинаковым именем. В настройках или
   окне ИИ можно включить обезличивание перед протоколом: сначала проверяются
   исходные тексты, затем черновик протокола до сохранения. Отмена останавливает
   этот сценарий. Исходные расшифровки остаются локально.

По умолчанию модели устанавливаются в:
  %LOCALAPPDATA%\WhisperGUI-Beta\models
При установке можно выбрать другую папку. Модель WeSpeaker для диаризации
включена в архив (около 13 МБ). Настройки и промпты находятся в:
  %APPDATA%\WhisperGUI-Beta

Обновления моделей: откройте «Модели и обновления...», нажмите «Проверить
обновления», отметьте нужные модели и запустите загрузку. Доступны Whisper
INT8 и FP16, WeSpeaker, Qwen3-8B и Qwen3-14B. Новая версия проверяется на GPU
до переключения. Предыдущая версия сохраняется для кнопки «Откатить версию».
При первом запуске бета копирует настройки стабильной версии в отдельный
профиль. Существующие модели можно использовать без повторной загрузки.

Для распознавания и диаризации нужен совместимый Intel GPU и его драйвер.
Программа использует GPU для обеих задач. На ПК без совместимого GPU эти
функции работать не будут. Обработка текста Qwen также использует GPU.

Не передавайте один только WhisperGUI.exe: ему нужна соседняя папка _internal.
Передавайте весь ZIP. Сведения о сторонних компонентах и моделях приведены
в THIRD_PARTY_NOTICES.txt.

Если программа не запускается, журнал ошибки создаётся в:
  %LOCALAPPDATA%\WhisperGUI-Beta\startup_error.log
