WhisperGUI 1.5.0 — готовый релиз для Windows x64
=============================================

1. Распакуйте весь архив WhisperGUI-1.5.0-win64.zip в отдельную папку.
2. Запустите WhisperGUI.exe. Python, OpenVINO и FFmpeg отдельно устанавливать
   не требуется.
3. Если модели Whisper ещё нет, программа предложит скачать и установить
   Whisper large-v3-turbo INT8 (около 0,9 ГБ). Нужен интернет только на время
   скачивания. Прерванную загрузку можно продолжить в этом же окне.
4. Для создания протоколов и резюме нажмите «Обработать текст ИИ». В этом окне
   можно установить Qwen3-8B INT4 (около 4,9 ГБ) или Qwen3-14B INT4
   (около 9,8 ГБ). Эти модели необязательны для распознавания речи.

По умолчанию модели устанавливаются в:
  %LOCALAPPDATA%\WhisperGUI\models
При установке можно выбрать другую папку. Модель WeSpeaker для диаризации
включена в архив (около 13 МБ). Настройки и промпты находятся в:
  %APPDATA%\WhisperGUI

Для распознавания и диаризации нужен совместимый Intel GPU и его драйвер.
Программа использует GPU для обеих задач. На ПК без совместимого GPU эти
функции работать не будут. Обработка текста Qwen также использует GPU.

Не передавайте один только WhisperGUI.exe: ему нужна соседняя папка _internal.
Передавайте весь ZIP. Сведения о сторонних компонентах и моделях приведены
в THIRD_PARTY_NOTICES.txt.

Если программа не запускается, журнал ошибки создаётся в:
  %LOCALAPPDATA%\WhisperGUI\startup_error.log
