# WhisperGUI

Приложение для локального распознавания аудио и видео, диаризации и составления протоколов на Intel GPU.

Код находится в `app/`, необходимая для сборки модель WeSpeaker — в `diarization/`. Запуск и сборка описаны в `docs/DEVELOPMENT.md`. Большие модели Whisper и Qwen устанавливаются через приложение.

Корень этой папки — единственный рабочий Git-репозиторий проекта. Готовые комплекты хранятся отдельно в `WhisperGUI_Releases/`, скачанные большие модели — в `turbo-gpu/` и `llm-models/`, личные записи и документы — в `local-data/`. Эти каталоги не попадают в коммиты. Старые копии программы больше не используются для разработки.

Рабочая версия закреплена в ветке `release/1.5` и теге `v1.5.0`. Разработка следующей версии ведётся в ветке `beta/2.0`.

Версия `2.0.0-beta.1` добавляет проверку и установку обновлений Whisper INT8/FP16, WeSpeaker и Qwen3-8B/14B. Новые версии проходят проверку файлов и GPU перед переключением; предусмотрен откат. Профиль беты отделён от стабильного релиза. Пользовательская инструкция — [docs/MODELS.md](docs/MODELS.md).

История изменений — [CHANGELOG.md](CHANGELOG.md), архитектура — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), команды сборки и ограничения проверок — [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md). Готовый EXE необходимо распространять вместе с папкой `_internal` в полном ZIP, а не одним файлом.

Правила работы с ветками и коммитами закреплены в [AGENTS.md](AGENTS.md). Подключение удалённого репозитория и публикация на GitHub выполняются отдельно; локальный Git не требует доступа к сети.
