# Rechka

Приложение для локального распознавания аудио и видео, диаризации, обезличивания расшифровок и составления протоколов на Intel GPU.

Код находится в `app/`, необходимая для сборки модель WeSpeaker — в `diarization/`. Запуск и сборка описаны в `docs/DEVELOPMENT.md`. Большие модели Whisper и Qwen устанавливаются через приложение.

Корень этой папки — единственный рабочий Git-репозиторий проекта. Готовые комплекты хранятся отдельно в `WhisperGUI_Releases/`, скачанные большие модели — в `turbo-gpu/` и `llm-models/`, личные записи и документы — в `local-data/`. Эти каталоги не попадают в коммиты. Старые копии программы больше не используются для разработки.

Релиз 2.0.0 закреплён тегом `v2.0.0` и веткой `release/2.0.0`; `main` содержит опубликованную версию. Версия 1.5 сохранена в `release/1.5` и `v1.5.0`. История разработки 2.0 остаётся в `beta/2.0`.

Релиз **2.0.0** объединяет распознавание аудио/видео и M4A, спикеров, локальные протоколы, обезличивание и обновления моделей. Готовая программа — в [GitHub Releases](https://github.com/iTylorn/rechka/releases). Распакуйте полный Windows ZIP и запустите `WhisperGUI.exe`. Нужен совместимый Intel GPU; Python и FFmpeg уже включены.

Настройки 2.0 хранятся отдельно в `%APPDATA%\WhisperGUI-2`, с импортом беты или 1.5 при первом запуске. Прежние профили не изменяются, модели повторно не скачиваются.

Версия `2.0.0-beta.3` декодирует аудиофайлы M4A (AAC и ALAC) встроенным FFmpeg с сохранением исходных каналов.

Версия `2.0.0-beta.2` добавляет пакетное обезличивание TXT/Markdown: локальный поиск сведений, единые метки, решения по отдельным вхождениям и повторную проверку. Настройка обезличивания перед ИИ передаёт проверенный текст в протокол и требует проверить черновик перед сохранением. Инструкция — [docs/PRIVACY.md](docs/PRIVACY.md).

Начиная с `2.0.0-beta.1` доступны проверка и установка обновлений Whisper INT8/FP16, WeSpeaker и Qwen3-8B/14B. Новые версии проходят проверку файлов и GPU перед переключением; предусмотрен откат. Профиль беты отделён от стабильного релиза. Пользовательская инструкция — [docs/MODELS.md](docs/MODELS.md).

История изменений — [CHANGELOG.md](CHANGELOG.md), архитектура — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), команды сборки и ограничения проверок — [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md). Готовый EXE необходимо распространять вместе с папкой `_internal` в полном ZIP, а не одним файлом.

Правила работы с ветками и коммитами закреплены в [AGENTS.md](AGENTS.md). Подключение удалённого репозитория и публикация на GitHub выполняются отдельно; локальный Git не требует доступа к сети.
